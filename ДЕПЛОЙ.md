# Как выложить «Рыбалку с Бибинто» в интернет

## Что нужно залить на сервер

| Файл | Зачем |
|---|---|
| `server.js` | сервер: раздаёт игру, регистрация, сохранения, топы, награды |
| `ribalka3d.html` | сама игра |
| `models.js` | модели альтушек (если поменял `.glb` — пересобери через `pack-models.ps1`) |
| `package.json` | чтобы хостинг понял, как запускать (`npm start`) |
| `Dockerfile` | если хостинг работает через Docker |

Внешних библиотек нет, `npm install` не нужен. Нужен **Node.js 18 или новее**.
Данные игроков сервер сам создаёт в папке `data/` (`db.json` с аккаунтами и `saves/` с сохранениями). **Эту папку бэкапь**.

## Проверить у себя

```bash
node server.js
```

Открой http://localhost:3000. Появится окно входа и регистрации.
Если открыть `ribalka3d.html` двойным кликом, как раньше, игра работает без аккаунта.

## Вариант 1. Свой VPS (Timeweb, Selectel, Aeza, любой с Ubuntu), примерно 200–400 ₽/мес

1. Поставь Node.js 20:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt install -y nodejs nginx
   ```
2. Залей файлы в `/opt/ribalka`. Например, `scp server.js ribalka3d.html models.js package.json root@IP:/opt/ribalka/`.
3. Запусти через pm2, чтобы сервер жил вечно и поднимался после перезагрузки:
   ```bash
   sudo npm i -g pm2
   cd /opt/ribalka && PORT=3000 TRUST_PROXY=1 pm2 start server.js --name ribalka
   pm2 save && pm2 startup
   ```
4. Настрой nginx в `/etc/nginx/sites-available/ribalka`, подставь свой домен:
   ```nginx
   server {
     server_name bibinto-fishing.ru;
     client_max_body_size 5m;
     location / { proxy_pass http://127.0.0.1:3000; proxy_set_header X-Forwarded-For $remote_addr; proxy_set_header Host $host; }
   }
   ```
   ```bash
   sudo ln -s /etc/nginx/sites-available/ribalka /etc/nginx/sites-enabled/ && sudo nginx -s reload
   ```
5. Включи HTTPS (бесплатно):
   ```bash
   sudo apt install -y certbot python3-certbot-nginx && sudo certbot --nginx -d bibinto-fishing.ru
   ```
   HTTPS обязателен: без него браузеры могут резать P2P-соединения (друзья, турниры, обмен).

## Вариант 2. Docker

```bash
docker build -t ribalka .
docker run -d --restart=always -p 3000:3000 -v ribalka-data:/data --name ribalka ribalka
```

## Вариант 3. Render / Railway / Fly.io (без своего сервера)

Залей папку в GitHub-репозиторий и создай на хостинге «Web Service» из него. Команда запуска: `npm start`.
**Важно:** подключи постоянный диск (Persistent Disk / Volume) и укажи переменную `DATA_DIR` с путём к нему. Иначе аккаунты сотрутся при каждом перезапуске.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | порт |
| `DATA_DIR` | `./data` | где хранить аккаунты и сохранения |
| `TRUST_PROXY` | выкл. | `1`, если сервер стоит за nginx: тогда лимиты считаются по настоящему IP игрока |
| `TZ_OFFSET_H` | `3` | часовой пояс для смены «дня» в ежедневных наградах (3 = Москва) |
| `ADMINS` | пусто | ники модераторов чата через запятую, например `ADMINS=Дима,Бибинто` |

## Чат и модерация

- Есть каналы «🌍 Общий» и «🛡️ Клан» и личные сообщения. Личные дойдут, даже если игрок не в сети.
- История хранится в `data/chat.json`, последние 5000 сообщений.
- Защита от спама: не чаще одного сообщения в 1,2 с, не больше 15 в минуту, одинаковые сообщения подряд нельзя.
- Каждый игрок может добавить другого в игнор (кнопка 🚫 в личке).
- Команды модератора пишутся прямо в чат:

| Команда | Что делает |
|---|---|
| `/mute ник минуты` | запрещает игроку писать на это время |
| `/unmute ник` | снимает мут |
| `/clear` | очищает общий чат |
| ✕ у сообщения | удаляет это сообщение |

- Сообщения приходят мгновенно: браузер держит запрос открытым до 25 секунд. У nginx стандартный `proxy_read_timeout` 60 с, этого хватает.

## Как это устроено

- **Аккаунты.** Ник от 3 до 16 символов, пароль от 6. Пароли хранятся в виде хэша (scrypt), их не видно даже в `db.json`. Вход живёт 30 дней. Есть защита от перебора: 20 попыток входа за 10 минут и не больше 5 новых аккаунтов в час с одного IP.
- **Сохранения.** Игра отправляет прогресс на сервер раз в 15 секунд и при закрытии вкладки. Если играть в двух вкладках или на двух устройствах сразу, сервер не даст старой копии затереть новую. Игра предложит загрузить свежий прогресс.
- **Ежедневные награды и «час в игре».** «День» и время в игре считает сервер, поэтому перевод часов на компьютере не помогает.
- **Топ игроков и кланов** собирается из сохранений всех игроков и обновляется раз в 30 секунд.
- **Друзья, турниры, рынок, войны кланов и обмен** по-прежнему идут напрямую между браузерами через бесплатный сервер PeerJS. Отдельно его поднимать не нужно.

## Честно про защиту от читеров

Деньги, альтушки и бои считаются в браузере игрока, а сервер только хранит сохранение. Тот, кто разбирается в DevTools, может подкрутить себе деньги, и они попадут в топ. Для игры с друзьями этого хватает. Если игра станет большой, следующий шаг — перенести продажу, награды и бои на сервер. Это отдельная крупная работа.
